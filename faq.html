FAST HACK CLUB

Frequently Asked Questions

What is this?

This is a coding club for the students of FAST NUCES Lahore, run by Muhammad Ali. Our objective is to learn programming together and to make cool projects!

What is Hack Club?

Hack Club is the world's largest nonprofit movement of teenagers making cool projects.

What's the difference between this and other societies?

FREE FOOD, free mentorship, and no registration fee. Beginner friendly.

Free food?

We often have snacks like pizza, or bubble tea at our workshops. These are funded directly by Hack Club, basically a grant given per project shipped.

What if I don't know how to code?

We got you! You'll be guided and taught at each and every step on how to build a project. There will also be one-on-ones if you need extra time to learn!

What's a ship?

A ship is a project that is publicly accessible along with it's source. Meaning that the project is deployed over the internet and it's code is published on a public repository on Github.

When do workshops happen?

Workshops usually happen every two weeks. In a workshop, you are introduced to a new program on which each member of the club will now work and ship a project to.

What's a coding session?

As simple hour-long workshops cannot cover the entire process of creating a project, you get tie to go home and continue building your project. If at any stage you find yourself stuck, or just wanna have fun while coding together, you can come over at a coding session to code with other members of the club.

How do grants work?

Every project that is shipped to a workshop first gets approved by Hack Club, then Hack Club returns a certain amount of coins based on how well the project is made. These coins are added to the club balance, which is one balance for the entire club. Using these coins, the club leader can purchase items from the club shop, which includes food grants, outing grant, PCB grant, and cool stuff like a Raspberry Pi, a Pincil, or some Hack Club merch! You can see the full shop when you become a member of the club.

Can I use AI for projects?

In one word, NO. Use of AI is not recommended as the stuff YOU make should truly be YOUrs, and other members are always available to help you in case you're struggling with something!

Are there any prerequisites?

Yup! You should have VS Code or something similar installed on your computer, along with Git and/or Github Desktop, which would also require you to create and authenticate a Github Account.

Can I join this? When and how?

Any student of FAST Lahore can join at any time! You can register now at this link.
